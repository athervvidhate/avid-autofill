Open tracker

    Advanced: use your own Google client

    1. In Google Cloud, enable the Google Sheets API and Google Drive API.
    2. Configure Google Auth Platform branding and audience. While the app is in testing, add the Google account you will use as a test user.
    3. Create a Web application OAuth client and add the exact authorized redirect URI below. Allow the drive.file, openid, and email scopes.

    Question bank

    Save answers you approve for reuse. Jev can select these answers for similar questions.

    Restrict company-specific answers to that company's application URL, such as https://jobs.ashbyhq.com/acme/. Check "Use on any application" only for answers that apply everywhere.

    Jev matching Experimental

    Fill more unanswered fields using your saved answers.

    When you click Fill this application, Jev receives unmatched field labels, available options, and descriptions of saved answers directly at TypeSafe AI. Mapping a dropdown or radio option also sends the selected saved answer. Your resume and complete profile are not sent.

    This first version handles text fields, native dropdowns, and radio groups. It chooses saved answers and does not write new responses. Review every filled answer before submitting.

    Your key is saved in this browser's extension storage, apart from your profile, so it stays after restarts and extension reloads. It is never shown again or included in a profile export. Remove key and turn off deletes it.
